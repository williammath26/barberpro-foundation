# BarberPro Foundation

Vamos iniciar o BarberPro, um SaaS de gestão de barbearias.

Quero utilizar o Lovable Cloud como backend, com PostgreSQL, autenticação, armazenamento e funções de backend.

O sistema deverá atender múltiplas barbearias, com isolamento dos dados de cada estabelecimento.

Neste primeiro momento:

Configure o Lovable Cloud.

Inicialize a estrutura do projeto React + TypeScript.

Não crie tabelas ainda.

Não desenvolva funcionalidades.

Não crie dados fictícios.

Avise quando a infraestrutura estiver pronta para iniciarmos a modelagem do banco de dados.

This project was built with [Lovable](https://lovable.dev).
