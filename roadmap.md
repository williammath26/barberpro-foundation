# Roadmap — BarberPro

## Concluído
- [x] Infraestrutura: Lovable Cloud ativo, projeto React + TypeScript inicializado.
- [x] Modelagem do banco: 10 tabelas, RLS, funções, gatilhos e índices.
- [x] Tela de login e cadastro (e-mail/senha, Google, Lovable) + redefinição de senha.
- [x] Cadastro da barbearia no painel (testado pelo usuário).
- [x] Módulo Serviços: nome, preço, duração, descrição e ativo/inativo (testes de regra passando).

- [x] Barbeiros e horários: cadastro, serviços de cada barbeiro, expediente semanal e folgas.

## Pendente
- [ ] Agenda: ver e criar agendamentos com bloqueio de horários ocupados.
- [ ] Clientes: cadastro e histórico.
- [ ] Equipe: convidar administradores e recepcionistas.
- [ ] Agendamento pelo cliente: página pública escolhendo serviço, barbeiro e horário.
- [ ] Página pública sem login: precisa de política de leitura anônima para barbearia, barbeiros e serviços ativos.
